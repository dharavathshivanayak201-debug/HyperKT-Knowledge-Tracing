# Upload guide

1. Create a private GitHub repository using the name selected for the manuscript.
2. Extract `HyperKT_GitHub_Source_Results.zip` and commit its contents.
3. Keep `HyperKT_Checkpoints_Large_Artifacts.zip` separately; if releasing large files, use GitHub Releases, Git LFS, or a DOI archive.
4. Audit licenses, dataset redistribution rights, notebook secrets, and output privacy before public release.
5. Update the manuscript Code Availability placeholder only after the real repository URL exists.
